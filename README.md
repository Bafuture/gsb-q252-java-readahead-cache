## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的存储底层读取延迟高，顺序访问时逐块读取太慢，随机访问时预读又会浪费。请从零实现一个存储读缓存与预读组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持按块的读缓存，缓存容量可配置并按访问情况淘汰；2) 支持预读：检测到顺序访问模式时提前读取后续若干块，需说明如何识别顺序模式（例如连续块命中次数）；3) 支持预读开关与预读深度动态调整：随机访问为主时降低预读，避免无效读取；4) 支持缓存一致性：底层块被更新时对应缓存必须失效，需有测试证明不会读到旧数据；5) 支持并发读：同一块的并发请求只触发一次底层读取，其余等待并复用结果；6) 提供统计：命中率、预读命中率、无效预读数与底层读取次数；7) 给出顺序与随机两种访问模式下开启与关闭预读的耗时对比；8) 测试覆盖缓存命中与淘汰、顺序预读、动态调整、一致性失效、并发去重与性能对比；`mvn -q verify` 一条命令跑通。
